# 사용자 흐름

## 핵심 사용자 여정

### 첫 방문

1. 사용자가 웹앱에 접속한다.
2. 제품의 핵심 기능을 한 화면에서 확인한다.
3. 이메일로 가입하거나 로그인한다.
4. 온보딩으로 이동한다.

### 온보딩

1. 가게 이름을 입력한다.
2. 업종을 선택한다.
3. 영업시간, 주소, 연락처, 대표 메뉴 또는 서비스를 입력한다.
4. 응대 톤을 선택한다.
5. 자주 묻는 질문을 1개 이상 등록한다.
6. 대시보드로 이동한다.

## 주요 작업 흐름

### 손님 문의 답장 생성

1. 대시보드에서 문의 답장을 선택한다.
2. 손님 문의 내용을 입력한다.
3. 답변 목적을 선택한다.
4. 필요하면 톤과 길이를 조정한다.
5. AI 답변 생성을 실행한다.
6. 결과를 확인한다.
7. 복사해서 채팅, DM, 문자, 댓글 등에 붙여넣는다.

### 리뷰 답글 생성

1. 대시보드에서 리뷰 답글을 선택한다.
2. 리뷰 내용을 붙여넣는다.
3. 리뷰 감정을 선택한다.
4. 사과, 감사, 재방문 유도 등 포함할 요소를 선택한다.
5. AI 답글 생성을 실행한다.
6. 결과를 복사한다.

### 홍보글 생성

1. 대시보드에서 홍보글을 선택한다.
2. 홍보 목적을 선택한다.
3. 상품, 이벤트, 기간, 혜택을 입력한다.
4. 게시 채널을 선택한다.
5. AI 홍보글 생성을 실행한다.
6. 결과를 복사하고 필요하면 다시 생성한다.

### FAQ 관리

1. 사이드 내비게이션에서 FAQ를 선택한다.
2. 질문과 답변을 추가한다.
3. 기존 FAQ를 수정하거나 삭제한다.
4. 저장된 FAQ는 AI 생성 시 자동으로 참고된다.

### 가게 정보 관리

1. 사이드 내비게이션에서 가게 정보를 선택한다.
2. 기본 정보, 영업 정보, 대표 상품, 응대 톤을 수정한다.
3. 저장 후 모든 AI 생성 기능에 반영된다.

## 재방문 흐름

1. 사용자가 로그인한다.
2. 대시보드에서 최근 사용 기능과 최근 생성 이력을 확인한다.
3. 필요한 문안 생성 기능으로 바로 이동한다.
4. 결과를 복사하거나 이전 이력을 참고한다.

## 예외 흐름

### 가게 정보가 없는 경우

- 생성 화면 상단에 가게 정보 입력을 안내한다.
- 최소 정보만 입력해도 생성할 수 있게 한다.

### FAQ가 없는 경우

- FAQ 없이도 생성 가능하게 한다.
- 생성 결과 하단에서 FAQ 등록을 유도한다.

### AI 생성 실패

- 실패 이유를 짧게 표시한다.
- 사용자가 다시 시도할 수 있게 한다.
- 입력 내용은 보존한다.

## UX 원칙

- 모든 핵심 작업은 3단계 안에 시작할 수 있어야 한다.
- 사장님이 작성해야 하는 입력은 최소화한다.
- 결과 화면에서 복사 버튼은 항상 명확하게 보인다.
- 모바일 한 손 사용을 우선한다.
