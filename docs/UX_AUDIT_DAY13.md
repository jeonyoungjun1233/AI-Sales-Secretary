# Day 13 UX 감사 리포트

## 1. 현재 사이트 확인 요약

Day 12까지 핵심 기능은 충분히 구현되어 있다. Day 13에서는 기능 추가보다 첫 사용자가 더 빨리 “이 앱이 내 답장, 리뷰, 홍보글 업무를 줄여준다”는 가치를 느끼도록 전환 흐름을 정리했다.

## 2. 랜딩페이지 개선점

- 메인 CTA를 `/demo`의 “1분 체험하기”로 고정했다.
- 보조 CTA를 `/agent`의 “오늘 액션 보기”로 정리했다.
- “복사해서 바로 쓰는 AI 알바생” 메시지를 추가해 실제 사용 장면을 더 분명하게 했다.

## 3. 1분 체험 개선점

- 업종 카드가 버튼처럼 보이도록 테두리, 그림자, 선택 강조를 강화했다.
- 선택된 업종에는 “선택됨” 표시를 넣었다.
- 업종 설명을 한 줄로 줄여 모바일에서 빠르게 읽히게 했다.

## 4. 대시보드 개선점

- “오늘 매출 액션”을 최상단 핵심 카드로 이동했다.
- 버튼 문구를 “오늘 액션 만들기”로 바꿔 다음 행동을 명확히 했다.
- 오늘 현황은 두 번째 카드로 내려 핵심 행동을 방해하지 않게 했다.

## 5. 오늘 매출 액션 개선점

- 결과 전 안내 문구를 “버튼 하나로 오늘 할 일 준비”로 명확히 했다.
- 액션 카드 버튼을 “복사”, “기록”, “일정”, “완료”로 짧게 바꿨다.
- 카드별 주요 행동이 한눈에 보이도록 버튼 영역을 압축했다.

## 6. 생성 화면 개선점

- 문의 답장 화면은 예약, 가격, 영업시간, 기타를 먼저 보이게 했다.
- 주차, 메뉴, 위치, 불편 문의는 “더 보기”로 접었다.
- 홍보글 화면은 예약, 이벤트, 신메뉴, 날씨를 먼저 보이게 했다.
- 마감 임박 홍보는 “더 보기”로 접었다.

## 7. 요금제 화면 개선점

- 프로 플랜을 “매일 홍보하고 리뷰 관리하는 사장님”에게 추천하는 플랜으로 강조했다.
- 프로 플랜에 “오늘 매출 액션과 주간 홍보 캘린더 포함” 강조 박스를 추가했다.
- 베이직은 혼자 운영하는 가게, 비즈니스는 여러 매장 운영 상황에 맞게 설명을 다듬었다.

## 8. 피드백 화면 개선점

- 제목을 “30초 의견”으로 줄였다.
- 질문은 실제 사용 의향, 필요한 기능, 적정 가격, 한마디 의견으로 정리했다.
- 제출 후 메시지를 “의견 감사합니다. 정식 버전에 반영하겠습니다.”로 간결화했다.

## 9. 세계 최고 앱 벤치마크 반영 내용

- Podium: 문의 응답을 매출 기회로 연결하는 CTA 강화
- Birdeye: 문의, 리뷰, 홍보를 한 화면의 액션 카드로 정리
- Square Marketing: 홍보글을 고객 유입 행동으로 표현
- Shopify: 복잡한 설정보다 빠른 시작 강조
- GoHighLevel: 답장, 일정, 기록 저장이 이어지는 흐름 유지
- Canva: 업종 선택과 빠른 체험을 설명 없이 누를 수 있게 개선
- Toss Bank: 짧은 문구, 큰 버튼, 모바일 우선 흐름 유지

## 10. 남은 개선 작업

- Supabase 원격 테이블 생성 후 서버 저장 검증
- 실제 사용자 테스트에서 `/demo` 이탈 지점 확인
- 프로 플랜 카피 A/B 테스트
- 로그인 또는 결제 대기자 수집 중 다음 우선순위 결정
