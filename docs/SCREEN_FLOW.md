# 화면 흐름

## 라우트 구조

- `/`: 로그인 전 소개 및 시작 화면
- `/login`: 로그인
- `/onboarding`: 첫 가게 정보 입력
- `/dashboard`: 홈 대시보드
- `/generate/inquiry`: 손님 문의 답장 생성
- `/generate/review`: 리뷰 답글 생성
- `/generate/promo`: 홍보글 생성
- `/faq`: FAQ 관리
- `/store`: 가게 정보 관리
- `/history`: 생성 이력
- `/settings`: 설정

## 화면별 목적

### 홈

- 제품의 핵심 가치를 보여준다.
- 로그인 또는 무료 시작 버튼을 제공한다.
- MVP에서는 긴 랜딩 페이지보다 즉시 시작을 우선한다.

### 로그인

- 이메일 로그인 또는 소셜 로그인을 제공한다.
- 로그인 후 가게 정보가 없으면 온보딩으로 보낸다.
- 가게 정보가 있으면 대시보드로 보낸다.

### 온보딩

- 가게 이름, 업종, 영업시간, 주소, 연락처, 대표 상품, 기본 톤을 입력한다.
- FAQ 1개 등록을 권장한다.
- 건너뛰기는 허용하되 대시보드에서 보완을 유도한다.

### 대시보드

- 3개 핵심 생성 기능으로 바로 진입한다.
- 가게 정보 완성도와 FAQ 개수를 보여준다.
- 최근 생성 이력을 보여준다.
- 다음 추천 작업을 1개만 제시한다.

### 손님 문의 답장 생성

- 문의 입력 영역
- 답변 목적 선택
- 톤 선택
- 생성 버튼
- 결과 패널
- 복사 버튼
- 다시 생성 버튼

### 리뷰 답글 생성

- 리뷰 입력 영역
- 리뷰 유형 선택
- 포함할 요소 선택
- 생성 버튼
- 결과 패널
- 복사 버튼

### 홍보글 생성

- 홍보 목적 선택
- 상품 또는 이벤트 입력
- 혜택, 기간, 채널 입력
- 생성 버튼
- 결과 패널
- 복사 버튼

### FAQ 관리

- FAQ 목록
- 질문 및 답변 추가 폼
- 수정과 삭제 액션
- 검색은 MVP 이후로 미룬다.

### 가게 정보 관리

- 기본 정보
- 영업 정보
- 대표 상품 또는 서비스
- 응대 톤
- 저장 버튼

### 생성 이력

- 생성 유형, 입력 요약, 결과 일부, 생성 일시를 보여준다.
- 이력 상세 보기와 복사를 제공한다.
- 필터는 MVP 이후로 미룬다.

### 설정

- 언어, 기본 톤, 계정 정보를 관리한다.
- 결제 설정은 MVP에서 제외한다.

## 모바일 내비게이션

- 하단 탭: 홈, 생성, FAQ, 가게
- 생성 탭을 누르면 문의 답장, 리뷰 답글, 홍보글 선택 메뉴를 보여준다.
- 주요 생성 화면에서는 복사 버튼을 하단 고정 영역에 둔다.

## 데스크톱 내비게이션

- 좌측 사이드바를 사용한다.
- 대시보드, 문의 답장, 리뷰 답글, 홍보글, FAQ, 가게 정보, 이력을 배치한다.
- 콘텐츠 영역은 입력과 결과를 2열로 구성할 수 있다.

## 상태 설계

- 빈 상태: 예시 입력과 시작 버튼 제공
- 로딩 상태: 생성 중 문구와 취소 불가 안내
- 성공 상태: 결과, 복사, 다시 생성 제공
- 실패 상태: 에러 메시지와 재시도 제공
