# Day 1 UI/UX 검토 리포트

## 1. 현재 목표 요약

AI 사장님 매출 비서는 소상공인, 자영업자, 1인 사업자가 손님 문의 답장, 리뷰 답글, 홍보글 작성 시간을 줄이도록 돕는 AI 업무 보조 SaaS다.

Day 1의 목표는 실제 기능 연결이 아니라, 사장님이 첫 화면에서 “이 앱은 내 답장과 홍보글 시간을 줄여주는 도구”라고 바로 이해하도록 랜딩페이지, 대시보드, 가게 정보 등록 기본 화면의 UI 방향을 잡는 것이다.

## 2. Day 1 구현 결과 전체 평가

전체적으로 Day 1 결과는 MVP의 첫인상을 보여주기에 충분한 수준까지 올라왔다. 랜딩페이지는 답장 미리보기 카드와 명확한 CTA를 통해 서비스 목적을 빠르게 전달하고, 대시보드는 오늘 할 일을 카드로 보여줘 사장님이 바로 눌러볼 수 있는 구조가 되었다.

수익화 관점에서는 “시간 절약” 메시지는 잘 보이지만, 아직 “월 구독료를 낼 만큼 반복적으로 쓰게 되는 이유”는 더 강화해야 한다. 다음 단계에서는 단순 문구 생성보다 “매일 쌓이는 문의, 리뷰, 홍보 업무를 한곳에서 처리한다”는 운영 효율 메시지가 더 선명해야 한다.

## 3. 랜딩페이지 검토

좋은 점:

- 첫 화면에서 “사장님, 손님 답장 놓치지 마세요.” 메시지가 강하게 보인다.
- 손님 질문과 추천 답장 미리보기 카드가 있어 사용 장면을 바로 이해할 수 있다.
- “복잡한 자동화 없이 복사해서 사용” 메시지가 초기 신뢰를 만든다.
- 문제, 기능, 사용 방법, CTA 흐름이 자연스럽다.

부족한 점:

- 유료 SaaS처럼 보이려면 “얼마나 시간이 줄어드는지”를 더 숫자로 보여줘야 한다.
- 업종별 예시가 아직 약하다. 카페, 네일샵, 미용실, 학원 등 타깃별 문구 예시가 있으면 전환율이 높아질 가능성이 크다.
- CTA는 좋지만 “무료로 시작하면 무엇을 할 수 있는지”가 더 구체적이어야 한다.

수익화 관점 개선:

- “하루 30분 절약”, “리뷰 답글 10개를 3분 안에” 같은 결과 중심 카피를 추가한다.
- “무료로 시작하기” 아래에 “카드 등록 없이 체험” 또는 “첫 10회 무료” 같은 낮은 진입 장벽 메시지를 붙인다.

## 4. 대시보드 검토

좋은 점:

- “사장님, 오늘은 어떤 일을 줄여드릴까요?” 문구가 사용자 친화적이다.
- 오늘 사용량, 추천 작업, 주요 기능, 최근 답장 미리보기가 있어 SaaS 앱처럼 보인다.
- 모바일 하단 CTA가 있어 핵심 행동인 답장 만들기로 쉽게 이동할 수 있다.

부족한 점:

- 지금은 모든 카드가 정적이다. Day 2에서는 최소한 mock 생성 결과라도 버튼 클릭 후 변화가 보여야 한다.
- 추천 작업의 우선순위 근거가 아직 약하다. “비 오는 날”, “리뷰 2개 대기”처럼 상황은 좋지만 더 일관된 데이터 표현이 필요하다.
- 사용량은 보이지만 요금제 전환으로 이어지는 가치 메시지는 아직 없다.

수익화 관점 개선:

- 무료 사용량이 줄어드는 모습을 보여주되 부담스럽지 않게 유료 전환 가능성을 준비한다.
- “이번 주 절약한 시간”, “처리한 고객 응대 수” 같은 성과 지표를 대시보드 상단에 배치한다.

## 5. 가게 정보 등록 화면 검토

좋은 점:

- 가게 이름, 업종, 영업시간, 주소, 전화번호, 대표 메뉴, 말투 선택이 포함되어 AI 문안 품질의 기본 재료를 잘 잡았다.
- 오른쪽 예시 답장 카드가 있어 가게 정보를 왜 입력해야 하는지 이해하기 쉽다.
- “오늘은 화면 확인 단계” 안내가 있어 아직 저장되지 않는다는 점이 명확하다.

부족한 점:

- 입력 완료 후 어떤 결과가 좋아지는지 더 즉각적인 피드백이 필요하다.
- 업종 선택은 기본 select보다 카드형 선택이 사장님에게 더 쉬울 수 있다.
- 대표 메뉴 외에 “우리 가게 특징” 입력이 있으면 홍보글 품질을 더 잘 설명할 수 있다.

수익화 관점 개선:

- 가게 정보를 많이 채울수록 답장 품질이 좋아지는 구조를 시각화한다.
- “가게 정보 완성도”를 0~100%로 보여주고, 완성도가 높을수록 더 좋은 답장을 받는다는 메시지를 넣는다.

- 형식: 인스타그램 정사각형 카드뉴스

Canva 시안의 핵심 스타일:

- 흰색과 민트 계열을 중심으로 한 밝은 SaaS 톤
- 큰 제목 중심의 직관적인 정보 구조
- 카드뉴스답게 한 장에 하나의 메시지를 강조하는 흐름
- 사장님 대상 서비스라는 점을 전면에 둔 후킹 카피

주의할 점:

- 일부 문구가 어색하다. 예: “AI가 귀하의 소통을 도와드려요”
- 5장 CTA에 더미 전화번호가 들어가 있어 실제 게시 전 삭제해야 한다.
- 4장 기능 목록이 압축되어 보여 가독성 개선이 필요하다.

## 7. Canva 디자인을 웹앱에 반영할 방향

Canva 시안에서 가져올 점:

- 한 화면에 하나의 메시지를 강하게 보여주는 구조
- 민트/화이트/진한 남색 중심의 밝은 신뢰감
- 큰 제목과 짧은 보조 문구의 조합
- 카드형 정보 블록과 부드러운 그림자
- “사장님 전용 AI 알바생” 같은 친근한 포지셔닝

웹앱 반영 방향:

- 랜딩페이지 섹션마다 핵심 메시지를 하나씩만 강조한다.
- 대시보드 카드에는 기능명보다 “줄어드는 일”을 먼저 쓴다.
- 기능 카드 아이콘과 색상 톤을 Canva 시안처럼 더 통일한다.
- CTA 문구는 “무료로 시작하기”만이 아니라 “답장 시간 줄이기”처럼 결과 중심으로 확장한다.

## 8. 수익화 관점에서 부족한 부분

- 무료 사용 후 유료 전환으로 이어지는 이유가 아직 약하다.
- “매출 증가”보다는 “시간 절약”만 강조되어 있어 지불 의사가 낮아질 수 있다.
- 반복 사용 동기가 더 필요하다. 예를 들어 매일 할 일, 주간 성과, 리뷰 관리 상태가 있어야 한다.
- 업종별 맞춤성이 더 드러나야 한다. 사장님은 “내 업종에도 맞나?”를 빠르게 판단한다.
- 가격을 직접 보여주지는 않더라도 “무료 플랜 10회 중 3회 사용” 같은 구독 구조의 씨앗은 유지하는 것이 좋다.

## 9. 사용자 이탈 가능성이 있는 부분

- 첫 사용자가 가게 정보를 입력하기 전에 가치를 충분히 못 느끼면 이탈할 수 있다.
- 저장 기능이 없으면 “눌러도 되는 앱”이라는 느낌이 약할 수 있다.
- 답장 생성 버튼을 눌렀을 때 결과가 나오지 않으면 데모 화면으로만 인식될 수 있다.
- CTA가 많아도 첫 핵심 행동이 분산되면 이탈할 수 있다. Day 2에서는 “답장 만들기”를 가장 강한 행동으로 둔다.

## 10. P0/P1/P2 개선 작업

### P0

- 손님 문의 답장 생성 화면 추가
- 리뷰 답글 생성 화면 추가
- 홍보글 생성 화면 추가
- 버튼 클릭 시 mock 결과가 나오는 미리보기 박스 구현
- 복사하기 버튼 동작 또는 복사 완료 상태 구현
- 사용자 화면에서 개발자 용어 제거 유지
- 대시보드의 핵심 CTA를 “답장 만들기”로 고정

### P1

- 가게 정보 입력값 local state 저장
- FAQ 관리 페이지 추가
- FAQ 추가, 수정, 삭제 mock 흐름 구현
- 업종별 예시 질문/답장 추가
- 가게 정보 완성도 표시
- “이번 주 절약한 시간” 지표 추가

### P2

- 요금제 화면 초안
- 사용량 제한 UI
- 업종별 템플릿 선택
- 생성 이력 화면
- Canva 카드뉴스 문구 정리 후 실제 마케팅 소재로 활용

## 11. Day 2 시작 전 확인할 것

- Day 2에서는 실제 OpenAI API를 연결하지 않는다.
- Supabase, 로그인, 결제도 구현하지 않는다.
- 모든 생성 결과는 mock 데이터로 처리한다.
- 사용자는 개발자가 아니라 바쁜 사장님이므로 버튼과 문구는 쉽게 유지한다.
- Day 2의 핵심은 “버튼을 누르면 결과가 나오는 느낌”을 만드는 것이다.
