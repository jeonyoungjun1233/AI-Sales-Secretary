# AI 사장님 매출 비서 사용 가이드

## 1. 이 앱은 무엇인가요?

사장님의 반복 업무를 줄여주는 AI 업무 비서입니다.

손님 문의 답장, 리뷰 답글, 홍보글, 일정을 한 번에 준비합니다.

## 2. 1분 체험 방법

1. `/guide`에서 사용법을 봅니다.
2. `/demo`로 이동합니다.
3. 업종을 고릅니다.
4. “예시 가게로 시작하기”를 누릅니다.
5. “오늘 액션 만들기”를 누릅니다.

## 3. 오늘 매출 액션 사용법

`/agent`에서 “오늘 액션 만들기”를 누릅니다.

그러면 문의 답장, 리뷰 답글, 홍보글, 일정 제안을 한 번에 볼 수 있습니다.

## 4. 문의 답장 만드는 법

1. `/generate/inquiry`로 이동합니다.
2. 손님 질문을 붙여넣습니다.
3. 말투와 문의 유형을 고릅니다.
4. “답장 만들기”를 누릅니다.
5. 결과를 확인하고 복사합니다.

## 5. 리뷰 답글 만드는 법

1. `/generate/review`로 이동합니다.
2. 리뷰 내용을 붙여넣습니다.
3. 리뷰 유형을 고릅니다.
4. “답글 만들기”를 누릅니다.
5. 결과를 확인하고 복사합니다.

## 6. 홍보글 만드는 법

1. `/generate/promo`로 이동합니다.
2. 홍보 목적과 업종을 고릅니다.
3. 올릴 채널을 고릅니다.
4. “홍보글 만들기”를 누릅니다.
5. 결과를 복사해서 사용합니다.

## 7. 기록과 일정 확인법

`/history`에서는 만든 문구를 다시 볼 수 있습니다.

`/calendar`에서는 오늘 할 일과 홍보 일정을 볼 수 있습니다.

## 8. 요금제 구조

현재는 베타 체험 단계입니다.

요금제 화면에는 무료 체험, 베이직, 프로, 비즈니스 플랜이 준비되어 있습니다.

실제 결제는 아직 연결하지 않았습니다.

## 9. 앞으로 추가될 기능

- 더 안전한 계정 저장
- 실제 결제와 구독
- 카카오톡, 인스타그램, 네이버 작업 연결
- 날씨와 상권에 맞는 홍보 추천
- 여러 매장 관리
- 영어 버전
