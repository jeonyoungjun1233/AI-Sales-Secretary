# MVP 개발 계획

## MVP 목표

7일 안에 소상공인이 가게 정보를 등록하고, 손님 문의 답장, 리뷰 답글, 홍보글을 생성해 복사할 수 있는 웹앱을 만든다.

## MVP 범위

### 포함 기능

- 이메일 기반 로그인
- 가게 정보 생성 및 수정
- FAQ 생성, 수정, 삭제
- 손님 문의 답장 생성
- 리뷰 답글 생성
- 홍보글 생성
- 생성 결과 복사
- 최근 생성 이력 목록
- 모바일 우선 반응형 UI

### 제외 기능

- 결제
- 팀 계정
- 외부 플랫폼 자동 연동
- 자동 발송
- 고급 분석 대시보드
- 이미지 생성
- 복잡한 권한 체계

## 7일 MVP 개발 계획

### Day 1: 제품 구조와 데이터 설계

- PRD, 사용자 흐름, 화면 흐름 확정
- Supabase 테이블 설계
- 앱 라우트 구조 정의
- OpenAI 프롬프트 전략 정의

### Day 2: 기본 앱 골격

- Next.js App Router 레이아웃 구성
- Tailwind 기반 기본 디자인 시스템 구성
- 로그인 및 로그아웃 화면 구성
- 보호 라우트 구조 준비

### Day 3: 가게 정보와 FAQ

- 가게 정보 입력 및 수정 화면 구현
- FAQ 목록, 추가, 수정, 삭제 구현
- Supabase RLS와 사용자별 데이터 분리 적용

### Day 4: AI 생성 기능 1차

- 손님 문의 답장 생성
- 리뷰 답글 생성
- 홍보글 생성
- 공통 생성 API 설계
- 가게 정보와 FAQ를 프롬프트에 반영

### Day 5: 결과 경험 개선

- 복사 버튼
- 톤 선택
- 플랫폼 선택
- 최근 생성 이력 저장
- 빈 상태, 로딩, 에러 상태 정리

### Day 6: QA와 안전장치

- 입력 검증
- AI 결과 면책 문구
- 기본 사용량 제한
- 모바일 화면 검수
- 주요 플로우 수동 테스트

### Day 7: 배포 준비

- Vercel 배포 환경 변수 설정
- Supabase 프로덕션 프로젝트 연결
- 린트와 빌드 확인
- MVP 데모 시나리오 정리
- 다음 개발 우선순위 업데이트

## MVP 성공 기준

- 신규 사용자가 5분 안에 첫 AI 문안을 생성한다.
- 사장님이 생성 결과를 복사해 실제 채널에 붙여넣을 수 있다.
- 가게 정보와 FAQ가 결과 문안에 반영된다.
- 모바일에서 주요 작업을 문제 없이 수행한다.

## 우선순위

### 반드시 필요

- 사용자 인증
- 사용자별 가게 정보
- FAQ 관리
- AI 문안 생성
- 결과 복사

### 있으면 좋은 것

- 생성 이력
- 톤 선택
- 플랫폼별 길이 조절
- 예시 입력값

### 나중에 할 것

- 결제
- 외부 플랫폼 연동
- 자동 발송
- 매출 분석

## 검증 방법

- 대표 업종 3개로 샘플 가게 정보 입력
- 긍정 리뷰, 부정 리뷰, 예약 문의, 가격 문의, 이벤트 홍보 시나리오 테스트
- 모바일 화면에서 3대 핵심 생성 기능 완료 여부 확인
- `npm run lint`와 `npm run build` 실행
