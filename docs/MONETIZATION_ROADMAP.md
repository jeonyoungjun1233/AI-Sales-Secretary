# 수익화 로드맵

## 1. 목표

AI 사장님 매출 비서는 단순 문구 생성기가 아니라, 사장님의 답장 시간, 리뷰 관리 시간, 홍보글 작성 시간을 줄여주는 업무 비서로 결제 이유를 만든다.

## 2. 무료 플랜

- 월 10회 문구 생성
- 하루 1회 오늘 매출 액션
- 문의 답장, 리뷰 답글, 홍보글 기본 생성
- 최근 생성 기록 20개
- 일정 10개
- FAQ 10개
- 가게 정보 1개

목표는 첫 사용자가 “바로 쓸 수 있다”는 경험을 얻는 것이다.

## 3. 베이직 월 9,900원

- 월 300회 문구 생성
- 하루 5회 오늘 매출 액션
- 생성 기록 300개
- 일정 100개
- FAQ 50개
- 가게 정보 기반 말투 반영
- 복사 기록과 절약 시간 요약

작은 가게 1곳을 운영하는 사장님에게 가장 쉬운 첫 유료 플랜이다.

## 4. 프로 월 29,000원

- 월 2,000회 문구 생성
- 업종별 오늘 매출 액션 추천
- 주간 홍보 캘린더
- 업종별 홍보글 추천
- 리뷰 유형별 답글 가이드
- 주간 업무 리포트
- 반복 질문 자동 정리
- 여러 채널용 문구 변환

매일 문의와 리뷰가 쌓이는 매장에 맞춘 플랜이다.

## 5. 비즈니스 월 59,000원

- 여러 매장 관리
- 매장별 오늘 매출 액션 추천
- 직원별 사용 권한
- 월간 성과 리포트
- 고급 FAQ 관리
- 캠페인 일정 관리
- 향후 외부 채널 연동 우선 제공

다매장, 프랜차이즈, 학원, 병원형 사업자까지 확장하는 플랜이다.

## 6. 유료 전환에 중요한 기능

- 생성 기록: 다시 복사할 수 있어 반복 업무의 가치를 체감한다.
- 일정 저장: 매일 들어와 확인할 이유를 만든다.
- FAQ 저장: 반복 문의를 줄이는 직접적인 시간 절약 효과가 있다.
- 가게 정보 저장: 사장님 말투와 업종에 맞는 결과를 만들기 위한 핵심 자산이다.
- 절약 시간 표시: 결제 전환에 필요한 숫자 기반 설득을 제공한다.

## 7. 가격 전략

초기에는 무료 플랜으로 사용 습관을 만들고, 생성 기록 수, 저장 가능한 FAQ 수, 월 생성 횟수, 리포트 기능을 기준으로 유료 전환을 유도한다.

## 8. Day 11 사용량 제한과 요금제 UX

Day 11에서는 실제 결제 연결 전 단계로 요금제 화면과 사용량 안내를 앱 안에 넣었다.

- 무료 체험: 월 10회 생성
- 베이직: 월 300회 생성
- 프로: 월 2,000회 생성
- 비즈니스: 여러 매장 운영 기준

사용량 카드는 대시보드, 개별 생성 화면, 오늘 매출 액션 화면에 표시한다.

무료 한도를 넘으면 외부 생성 호출 전에 안내를 보여주고 `/pricing`으로 이동하도록 한다.

이 구조는 OpenAI 비용을 보호하면서도 사용자가 자연스럽게 유료 플랜의 필요성을 이해하게 만든다.

## 9. Day 7 이후 수익화 과제

- 무료 사용량 한도 UI 설계
- 플랜 비교 화면 설계
- 절약 시간 기반 업그레이드 문구 작성
- 실제 결제 연결 전 가격 민감도 검증
- 한국 소상공인용 카드뉴스와 랜딩페이지 메시지 A/B 테스트

## 10. Day 9 베타 데모와 유료 전환 포인트

- 서버 저장: 사장님의 업무 기록이 유지된다는 신뢰를 만든다.
- 생성 기록: 이전 문구를 다시 복사할 수 있어 반복 사용 이유가 생긴다.
- 일정 관리: 매일 앱을 열어볼 이유가 생긴다.
- FAQ 저장: 반복 질문을 줄이는 직접적인 시간 절약을 보여준다.
- 업종별 템플릿: 프로 플랜에서 차별화할 수 있는 핵심 기능이다.

베타 테스트에서는 월 9,900원 결제 가능성과 가장 자주 쓸 기능을 먼저 확인한다.

## 11. Day 10 오늘 매출 액션 포지셔닝

“오늘 매출 액션”은 프로 플랜의 핵심 기능으로 키운다.

- 무료: 하루 1회 체험
- 베이직: 하루 5회 사용
- 프로: 업종별 추천과 주간 홍보 캘린더
- 비즈니스: 여러 매장별 액션 추천

이 기능은 단순 문구 생성보다 “오늘 무엇을 해야 하는지 알려주는 비서”에 가깝기 때문에 더 높은 지불 이유를 만든다.
