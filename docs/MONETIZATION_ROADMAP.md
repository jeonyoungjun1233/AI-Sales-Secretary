# 수익화 로드맵

## 1. 수익화 목표

AI 사장님 매출 비서는 단순 문구 생성기가 아니라, 사장님의 반복 응대, 리뷰 관리, 홍보글 작성, 일정 정리를 줄여주는 업무 비서로 결제 이유를 만든다.

핵심 결제 근거는 다음 세 가지다.

- 답장 시간을 줄인다.
- 매출 기회를 놓치지 않게 한다.
- 가게 정보와 기록이 쌓일수록 더 편해진다.

## 2. 무료 체험

- 가격: 0원
- 월 생성 10회
- 하루 1회 오늘 매출 액션
- 가게 1개
- 최근 기록 제한
- 기본 문의 답장, 리뷰 답글, 홍보글 생성

목표는 첫 사용자가 1분 안에 “이거 바로 쓸 수 있겠다”를 느끼게 만드는 것이다.

## 3. 베이직: 월 9,900원

- 월 생성 300회
- 생성 기록 저장
- FAQ 저장
- 일정 저장
- 가게 정보 기반 답변
- 최근 기록 다시 복사

1인 매장, 카페, 음식점, 네일샵처럼 사장님이 직접 답장과 홍보를 챙기는 사업자에게 맞는 첫 유료 플랜이다.

## 4. 프로: 월 29,000원

- 월 생성 2,000회
- 업종별 고급 템플릿
- 오늘 매출 액션 고급 추천
- 주간 홍보 캘린더
- 고급 말투 설정
- 리뷰 유형별 답글 가이드

프로 플랜의 핵심은 “오늘 뭘 해야 하지?”를 앱이 먼저 정리해주는 것이다.

Day 13 기준 프로 플랜은 “매일 홍보하고 리뷰 관리하는 사장님”에게 가장 잘 맞는 플랜으로 포지셔닝한다. 무료와 베이직이 기본 생성과 저장 중심이라면, 프로는 오늘 매출 액션과 주간 홍보 캘린더를 통해 매일 들어올 이유를 만든다.

## 5. 비즈니스: 월 59,000원

- 여러 매장 관리
- 직원 계정
- 매장별 일정
- 우선 지원
- 향후 자동 연동 우선 제공

여러 매장 또는 직원과 함께 운영하는 소상공인, 프랜차이즈형 사업자를 위한 확장 플랜이다.

## 6. Day 12 빠른 체험의 수익화 역할

`/demo`는 결제 전환을 위한 첫 경험이다.

- 업종을 고르기만 하면 가게 예시가 준비된다.
- 오늘 매출 액션으로 답장, 리뷰, 홍보, 일정까지 한 번에 보여준다.
- 설정 부담 없이 앱의 가치를 1분 안에 체험하게 한다.
- 발표와 베타 테스트에서 가격 민감도 질문으로 이어진다.

빠른 체험은 무료 체험 사용자가 베이직 또는 프로 플랜의 필요성을 이해하게 만드는 진입점이다.

## 7. Day 13 전환 UX 개선의 수익화 역할

Day 13에서는 새 결제 기능을 붙이지 않고도 전환 가능성을 높이는 화면 개선을 진행했다.

- 랜딩 CTA를 1분 체험과 오늘 매출 액션으로 정리했다.
- 대시보드 최상단에 오늘 매출 액션을 배치했다.
- 생성 화면의 선택지를 줄여 첫 사용 부담을 낮췄다.
- 프로 플랜에 오늘 매출 액션과 주간 홍보 캘린더 포함 메시지를 강조했다.
- 피드백 화면을 30초 설문처럼 줄여 가격 민감도를 더 쉽게 확인할 수 있게 했다.

## 8. 유료 전환에 중요한 기능

- 생성 기록: 이전 문구를 다시 복사할 수 있어 반복 사용 이유가 생긴다.
- 일정 관리: 매일 들어올 이유를 만든다.
- FAQ 저장: 반복 문의 답장을 줄인다.
- 가게 정보 저장: 내 가게에 맞는 말투와 내용을 만든다.
- 오늘 매출 액션: 프로 플랜의 대표 차별화 기능이 된다.

## 9. 아직 구현하지 않은 수익화 기능

- 실제 결제 연동
- 로그인 기반 플랜 관리
- 결제 상태에 따른 실제 기능 제한
- 매장별 권한 관리
- 세금계산서 또는 영수증 처리
