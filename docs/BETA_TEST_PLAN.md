# 베타 테스트 계획

## 1. 테스트 대상

- 카페
- 음식점
- 네일샵
- 미용실
- 학원
- PT샵

## 2. 테스트 질문

- 이 앱을 실제로 쓸 것 같은가?
- 가장 필요한 기능은 무엇인가?
- 월 얼마면 결제할 의향이 있는가?
- 답장, 리뷰, 홍보글, 일정 중 가장 중요한 기능은 무엇인가?
- 결과 문구를 그대로 복사해서 쓸 수 있는가?

## 3. 테스트 시나리오

1. 가게 정보를 입력한다.
2. FAQ를 2개 이상 등록한다.
3. 손님 문의 답장을 만든다.
4. 홍보글을 만든다.
5. 일정을 등록한다.
6. 기록 화면에서 만든 문구를 다시 확인한다.
7. 새로고침 후에도 데이터가 유지되는지 확인한다.

## 4. 성공 기준

- 3명 이상이 다시 쓰고 싶다고 응답한다.
- 2명 이상이 월 9,900원 이상 결제 가능성이 있다고 응답한다.
- 가장 많이 쓰고 싶은 기능 1개가 명확히 확인된다.
- 사용자가 첫 답장 생성까지 3분 안에 도달한다.

## 5. 관찰 포인트

- 가게 정보 입력에서 막히는지 확인한다.
- 문의 답장 결과가 자연스러운지 확인한다.
- 홍보글이 실제 업로드 가능한 수준인지 확인한다.
- 기록 화면이 재사용 가치로 느껴지는지 확인한다.
- 일정 화면이 매일 들어올 이유를 만드는지 확인한다.
