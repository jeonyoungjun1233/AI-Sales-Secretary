# 발표용 데모 시나리오

## 1. 발표 시작 전 준비

- 프로덕션 URL: https://ai-sales-secretary.vercel.app/
- 브라우저는 모바일 폭으로 준비한다.
- 새 브라우저 또는 시크릿 창에서 시작하면 체험 흐름이 깔끔하다.
- Supabase 원격 테이블이 없어도 브라우저 저장으로 데모가 이어지는지 확인한다.

## 2. 최종 발표 흐름

1. `/submission`에 접속한다.
2. 앱 한 줄 소개를 말한다.
3. `/guide`에서 사용법을 보여준다.
4. `/demo`에서 카페를 선택한다.
5. “예시 가게로 시작하기”를 누른다.
6. `/agent`에서 “오늘 액션 만들기”를 누른다.
7. 홍보글 액션을 복사한다.
8. 일정 액션을 달력에 추가한다.
9. `/history`에서 저장된 기록을 확인한다.
10. `/calendar`에서 추가된 일정을 확인한다.
11. `/pricing`에서 수익화 구조를 설명한다.
12. `/roadmap`에서 앞으로 업데이트 방향을 설명한다.

## 3. 발표 핵심 멘트

“이 앱은 단순 문구 생성기가 아니라, 사장님의 오늘 할 일을 정리하고 답장, 리뷰, 홍보, 일정까지 이어주는 AI 매출 비서입니다.”

- 1분 체험으로 누구나 바로 써볼 수 있습니다.
- 오늘 매출 액션은 어떤 기능을 눌러야 할지 고민을 줄입니다.
- 사장님은 결과를 확인하고 복사해서 안전하게 사용합니다.
- 기록과 일정이 쌓이면 매일 다시 들어올 이유가 생깁니다.
- 요금제와 로드맵으로 실제 SaaS 수익화 방향을 보여줍니다.

## 4. 보여줄 가치

- 문의 응답 속도 향상
- 리뷰 관리 부담 감소
- 오늘 올릴 홍보글 준비
- 일정 관리로 재방문 이유 생성
- 기록 저장과 계정 화면으로 유료 전환 근거 강화

## 5. 실패 시 대처

- 오늘 액션 생성이 막히면 `/generate/inquiry`에서 문의 답장을 직접 시연한다.
- 사용량 제한 안내가 나오면 `/pricing`에서 요금제 구조를 설명한다.
- Supabase 저장 확인이 안 되면 브라우저 저장으로 데모가 유지된다고 설명한다.
