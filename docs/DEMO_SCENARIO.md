# 발표용 데모 시나리오

## 1. 데모 목표

사장님이 여러 기능을 고르지 않아도 “오늘 매출 액션” 버튼 하나로 답장, 리뷰, 홍보, 일정을 한 번에 준비할 수 있음을 보여준다.

## 2. 데모 흐름

1. `/dashboard`에 접속한다.
2. 상단의 “오늘 매출 액션” 카드를 보여준다.
3. “바로 만들기”를 눌러 `/agent`로 이동한다.
4. “오늘 액션 만들기”를 누른다.
5. 문의 답장, 리뷰 답글, 홍보글, 일정 제안이 한 화면에 생성되는 것을 보여준다.
6. 홍보글 액션에서 “복사하기”를 누른다.
7. 일정 제안에서 “일정에 추가”를 누른다.
8. 문의 또는 리뷰 액션에서 “기록에 저장”을 누른다.
9. `/history`에서 저장된 문구를 확인한다.
10. `/calendar`에서 추가된 일정을 확인한다.

## 3. 발표 핵심 멘트

- “사장님은 어떤 기능을 눌러야 할지 고민하지 않아도 됩니다.”
- “오늘 할 일을 버튼 하나로 정리합니다.”
- “답장, 리뷰, 홍보, 일정까지 한 번에 준비합니다.”
- “자동 전송이 아니라 사장님이 확인하고 복사하는 안전한 방식입니다.”
- “가게 정보, FAQ, 이전 기록이 쌓일수록 더 내 가게에 맞는 비서가 됩니다.”

## 4. 보여줄 가치

- 답장 속도 향상
- 리뷰 관리 부담 감소
- 오늘 올릴 홍보글 준비
- 일정 관리로 재방문 습관 형성
- 기록 저장으로 유료 전환 근거 강화
