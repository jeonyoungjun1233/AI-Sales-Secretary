# 발표용 데모 시나리오

## 1. 발표 시작 전 준비

- 프로덕션 URL: https://ai-sales-secretary.vercel.app/
- 브라우저는 모바일 폭 또는 기본 앱 쉘 화면으로 준비한다.
- 사용량 제한에 걸릴 수 있으므로, 가능하면 새 브라우저 또는 시크릿 창에서 시작한다.
- Supabase 원격 테이블이 아직 준비되지 않아도 브라우저 저장으로 데모가 이어지는지 확인한다.

## 2. 데모 흐름

1. 프로덕션 URL에 접속한다.
2. 랜딩페이지에서 “1분 체험하기”를 클릭한다.
3. `/demo`에서 “카페” 예시를 선택한다.
4. “예시 가게로 시작하기”를 클릭한다.
5. “예시 가게를 준비했어요.” 피드백을 보여준다.
6. “오늘 액션 만들기”를 눌러 `/agent`로 이동한다.
7. `/agent`에서 “오늘 액션 만들기”를 클릭한다.
8. 문의 답장, 리뷰 답글, 홍보글, 일정 제안이 한 화면에 나오는지 보여준다.
9. 홍보글 액션에서 “복사하기”를 클릭한다.
10. 일정 액션에서 “일정에 추가”를 클릭한다.
11. 문의 또는 리뷰 액션에서 “기록에 저장”을 클릭한다.
12. `/history`에서 저장된 문구를 확인한다.
13. `/calendar`에서 추가된 일정을 확인한다.
14. `/pricing`에서 무료, 베이직, 프로, 비즈니스 플랜을 설명한다.
15. `/feedback`에서 베타 테스트 의견을 받을 수 있음을 보여준다.

## 3. 발표 핵심 멘트

“이 앱은 단순 문구 생성기가 아니라, 사장님의 오늘 할 일을 정리하고 답장, 리뷰, 홍보, 일정까지 이어주는 AI 매출 비서입니다.”

- 사장님은 어떤 기능을 눌러야 할지 고민하지 않아도 됩니다.
- 1분 체험으로 가게 예시를 넣고 바로 가치를 확인할 수 있습니다.
- 오늘 매출 액션은 답장, 리뷰, 홍보, 일정을 한 번에 준비합니다.
- 자동 전송이 아니라 사장님이 확인하고 복사하는 안전한 방식입니다.
- 가게 정보와 기록이 쌓일수록 더 내 가게를 아는 비서처럼 작동합니다.

## 4. 보여줄 가치

- 문의 응답 속도 향상
- 리뷰 관리 부담 감소
- 오늘 올릴 홍보글 준비
- 일정 관리로 매일 다시 들어올 이유 생성
- 기록 저장과 사용량 카드로 유료 전환 근거 강화

## 5. 실패 시 대처

- 오늘 액션 생성이 막히면 `/generate/inquiry`에서 문의 답장을 직접 시연한다.
- Supabase 저장 확인이 안 되면 브라우저 저장으로 이어진다고 설명한다.
- 사용량 제한 안내가 나오면 `/pricing`에서 수익화 구조를 설명하는 흐름으로 전환한다.
