# AI 사장님 매출 비서 PRD

## 제품 개요

AI 사장님 매출 비서는 한국 및 글로벌 소상공인, 자영업자가 반복적인 고객 응대와 홍보 업무를 빠르게 처리하도록 돕는 AI 업무 보조 SaaS 웹앱이다.

## 문제 정의

소상공인은 매출을 올려야 하지만 고객 문의, 리뷰 관리, 홍보글 작성에 많은 시간을 쓴다. 바쁜 영업 중에도 친절하고 일관된 답변을 작성해야 하며, 플랫폼별 톤과 길이를 맞추는 일도 부담이다.

## 목표 사용자

- 음식점, 카페, 미용실, 헬스장, 학원, 숙박업 등 문의와 리뷰가 많은 자영업자
- 네이버, 카카오, 인스타그램, 구글, 배달앱 리뷰와 문의를 직접 관리하는 소규모 사업자
- 마케팅 담당자가 없고 매일 10분 안에 고객 응대와 홍보 문안을 처리하고 싶은 사장님
- 향후 영어권 로컬 비즈니스 오너와 다국어 응대가 필요한 사업자

## 핵심 가치

- 반복 답변 작성 시간을 줄인다.
- 가게 정보와 FAQ 기반으로 더 정확한 답변을 생성한다.
- 리뷰 답글과 홍보글의 톤을 일정하게 유지한다.
- AI 사용 경험이 적은 사장님도 바로 쓸 수 있는 단순한 화면을 제공한다.

## MVP 핵심 기능

1. 손님 문의 답장 생성
2. 리뷰 답글 생성
3. 홍보글 생성
4. FAQ 관리
5. 가게 정보 관리

## 주요 시나리오

### 손님 문의 답장

사장님이 고객 문의 내용을 붙여넣고 답변 목적을 선택하면, AI가 가게 정보와 FAQ를 반영해 친절한 답장을 생성한다.

### 리뷰 답글

사장님이 리뷰 내용을 입력하고 리뷰 유형을 선택하면, AI가 감사, 사과, 재방문 유도 문구를 포함한 답글을 생성한다.

### 홍보글

사장님이 홍보 목적, 상품, 이벤트 내용을 입력하면 인스타그램, 네이버 소식, 문자 메시지 등에 맞는 홍보글을 생성한다.

## 성공 지표

- 첫 답변 생성까지 3분 이하
- 가입 후 첫 세션에서 문안 생성 완료율 70% 이상
- 생성 문안 복사율 50% 이상
- FAQ 또는 가게 정보 등록률 40% 이상
- 주 2회 이상 재방문 사용자 비율 25% 이상

## 우선순위

### P0

- 가게 정보 등록
- FAQ 등록, 수정, 삭제
- 손님 문의 답장 생성
- 리뷰 답글 생성
- 홍보글 생성
- 생성 결과 복사

### P1

- 생성 이력 저장
- 톤 선택
- 언어 선택
- 기본 사용량 제한
- 로그인 및 사용자별 데이터 분리

### P2

- 플랫폼별 템플릿
- 다국어 번역
- 팀 계정
- 예약, 주문, 매출 데이터 연동

## 제외해야 할 기능

- POS, 배달앱, 예약앱 실시간 연동
- 자동 답변 발송
- 결제 및 구독 과금
- 고급 CRM
- 직원 권한 관리
- 매출 예측
- 이미지 생성 기반 홍보물 제작
- 복잡한 캠페인 자동화

## 향후 확장 기능

- 네이버 플레이스, 구글 비즈니스, 카카오 채널 연동
- 배달앱 리뷰 자동 수집
- 매출 데이터 기반 오늘의 액션 추천
- 업종별 AI 프롬프트 패키지
- 다국어 고객 응대
- SNS 콘텐츠 캘린더
- 문자 또는 카카오 알림톡 홍보 발송
- 프랜차이즈 또는 다점포 관리

## 주요 리스크

- AI 답변이 실제 가게 정책과 다를 수 있다.
- 사장님이 초기 가게 정보 입력을 번거롭게 느낄 수 있다.
- 과도하게 일반적인 답변은 제품 차별성을 떨어뜨린다.
- 한국어 고객 응대 톤이 업종과 플랫폼에 맞지 않으면 신뢰가 낮아진다.

## 제품 원칙

- 사장님이 생각할 시간을 줄이고 바로 복사해 쓸 수 있게 만든다.
- 복잡한 설정 대신 좋은 기본값을 제공한다.
- AI 결과는 항상 사용자가 확인하고 복사하는 방식으로 제공한다.
- 가게 정보와 FAQ를 제품의 정확도 자산으로 삼는다.
